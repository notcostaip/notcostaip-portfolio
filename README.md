### &nbsp; 📦 Como rodar localmente

</div>

```bash
npm install
```

### 2. Inicie o servidor de desenvolvimento
```bash
npm run dev
```

### 3. Acesso
Abra seu navegador em [http://localhost:3000](http://localhost:3000)
